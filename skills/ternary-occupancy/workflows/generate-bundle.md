Self-check \(F\) afters are discarded and that band is retried. Max 3 attempts per band (first + 2 regenerations). \(H \neq I\) and same-face are not regeneration triggers.

## Step 0 — Evidence

Look at the running UI of the named screen. Do not assign bands from code or memory. Identify the styling system (Tailwind / CSS / CSS-in-JS). Do not add a second system.

## Step 1 — Floor

Floor means clauses **1, 3–7** in `references/judge-tree.md`. Clause 2 stays in the generation check but is not the floor inspector’s job. Copy floor 1, 3–7 and clause 2 into all three worktree contracts with the same wording.

Do not commit floor or clause-2 fixes to a shared base and then branch.

\(G^-\) work is that list + local craft. \(G\) / \(G^\star\) is the same list + the band contract. No band is excused from the floor.

## Step 2 — Current face

In one sentence, say how the screen is remembered now, using the 7 face dimensions. \(G^-\) must not break that sentence. \(G^\star\) may replace exactly one point in it.

## Step 3 — Bind band contracts

`references/band-*.md` are 4-axis templates. The parent translates them into this screen’s vocabulary and writes **one local contract file per worktree**.

A generation unit reads only the one contract file in its worktree. Do not load all three static templates into one context.

## Step 4 — Isolated generation

Implement the three bands in **separate contexts and separate git worktrees (or clones)**. Do not emit three versions in one conversation.

Implementation is three `Task` calls, or three new conversations (one per band). When using `Task`, the invocation starts with `# Title` then the Codex/Cursor mapping table in `SKILL.md`.

Done means three worktrees remain. Checkout / revert on one tree does not count.

Prefer four instances (before + 3 after) on separate ports (example `:3000`–`:3003`). If the host cannot hold four ports, launch the remaining worktrees in sequence for isolated presentation. Swapping one tree is not that exception.

## Step 5 — Self-check (parent only)

The parent reads `references/judge-tree.md`. Generation units do not.

Walk the tree on each after, one at a time, with \(I\) hidden. **Regenerate only when the leaf is \(F\)** (max 3 attempts per band). Do not regenerate for \(H \neq I\). Record same-face; do not regenerate for it. Runtime: incomplete if same-face or a band is \(F\) three times. Author calibration: same-face is still rated; three-times-\(F\) is generation-incomplete and is not rated.

If a band contracts motion, freeze one rest frame plus a run of frames that show the motion before rating. Answer the forced question on those frames, pointing to 2+ repeats.

## Step 6 — Present

Show the asker each after as **before + that after only**, in sequence. No three-up. Hide intended-band names. Do not bring three band raters at runtime.
